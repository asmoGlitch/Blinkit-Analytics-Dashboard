# 🛒 BlinkIT Grocery Data Analysis

## 📊 Project Overview

This project analyzes **BlinkIT grocery sales data** using Microsoft Excel to identify sales trends, customer preferences, outlet performance, and product-level insights.

The project includes data cleaning, analysis, visualization, and an interactive Excel dashboard designed to present key business insights in an easy-to-understand format.

## 🎯 Objectives

* Analyze overall grocery sales performance
* Identify top-performing product categories
* Compare sales across different outlet types and locations
* Analyze the impact of outlet size on sales
* Compare Low Fat and Regular products
* Understand product visibility and its relationship with sales
* Evaluate outlet performance based on establishment year
* Create an interactive Excel dashboard for business insights

## 📈 Dashboard

The Excel dashboard provides a visual overview of BlinkIT's grocery sales performance and allows users to explore important business metrics.

### Dashboard KPIs

* **Total Sales**

* **Product Category Performance**

### Key Analysis Areas

* 💰 Total Sales Performance

* 🏪 Outlet Performance
* 📍 Sales by Location Tier
* 🥛 Sales by Fat Content
* 📊 Sales by Outlet Type
* 📅 Outlet Establishment Trends
* ⭐ Customer Ratings
* 👁️ Item Visibility

## 🔍 Key Insights

The analysis focuses on identifying:

* Which product categories generate the highest sales
* Which outlet types perform best
* How outlet location and size influence sales
* Differences between Low Fat and Regular products
* Products with higher/lower visibility
* Trends in sales based on outlet establishment year
* Relationship between customer ratings and sales performance
